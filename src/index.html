Dark Theme Toggle Switch

Version 1.2, made by Pitri. This is a small test page to show the dark mode toggle switch I made. It's by far not a new idea. There are plenty of similar animated toggle switches made by people who enjoy showing their fancy designs to the world. So, I don't claim the idea - far from it. What I do, however, is claim this particular implementation.

I wanted to see how far I can push the aesthetics of such a button without relying on any kind of external image file (including base64 embedding in the CSS file). I also decided to not rely on JavaScript.

How to use it

In order to use it for yourself, link the stylesheet file in the website header, and create the toggle element (with the class .theme-toggle) somewhere on the page. It will automatially glue itself to the top-right corner of the screen, and remain there even if you scroll down. I consider obstructed text after scrolling an acceptable sacrifice, unless it's in the first line. If you can not rule out text overlapping the top right corner, you should add a spacer element (with the class .theme-toggle-spacer) as the first element in the <body>. It acts as an appropriately sized element that forces text to flow around it. You can try it out by creating a collision between the switch and the website title (by zooming or window resizing).

CSS variables

The :root element defines a list of variables that can be customized:

--theme-toggle-width: 4rem Width of the outer toggle element.
--theme-toggle-height: 2rem Height of the outer toggle element.
--theme-toggle-margin: 1rem Distance to the website border.
--theme-toggle-pin-size: 1.6rem Diameter of the round pin inside the toggle element.
--theme-color-dark: #111 Dark color of the theme.
--theme-color-light: #eee Bright color of the theme.

The following variables are then deduced in :root, conditionally depending on which mode we are currently in. The colors in body are set to these, so most of the website design should already be configured. The variables are still available in case there's a deeper element which needs some extra styling.

--theme-color-text: Foreground/text/content color.
--theme-color-back: Background color.

Other theming advice

With changing background and text brightness, the usage of other highlight colors is slightly harder. Either you go through the effort of defining each color twice (once for light mode and once for dark mode), or you can utilize the CSS color-mix feature to nudge a chosen color closer to the text color (assuming you have a CSS variable for that). The higher the percentage of the chosen color, the further it will stray away from the general text color.

This example defines red, orange, yellow, green, cyan, blue, purple, magenta and gray this way.

Code snippets

Embedding the stylesheet: <link rel="stylesheet" href="theme_toggle.css">
Button element: <input type="checkbox" class="theme-toggle" title="Toggle dark mode" aria-label="Toggle dark mode" />
Spacer element: <div class="theme-toggle-spacer"></div>
Adaptive color example: color-mix(in oklab, #73f 60%, var(--theme-color-text)); Avoid very bright or dark colors, as that will introduce inconsistent contrast across light and dark mode.

Changelog

Version 1.0 (2025-01-28)

  • Designed the sun and moon slider.
  • Requires nested divs with specific IDs: one for the slider and one for the celestial body inside.
  • Embedding the javascript file does the rest.
  • It uses localStorage to remember the previous setting.
  • If that is not set, the initial theme gets deduced from the system preferences.

Version 1.1 (2026-03-28)

  • The switch is now an input checkbox and does not need an inner element for the pin/celestial body.
  • This makes this a pure CSS solution, making JavaScript obsolete for the core functionality.
  • Unfortunately, this version loses the system preference checks.

Version 1.2 (2026-09-20)

  • Website colors and button animations are now inverted if the user prefers light mode.
  • This makes dark mode the default for anyone who has no preference.
  • Accessibility feature: Animation doesn't play in reduced motion mode.
  • Accessibility feature: Keyboard element highlight support.

That's about it. Enjoy your theme toggle switch! — Pitri
