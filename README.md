# CSS Theme Toggle

A very small CSS-only dark mode toggle, ideal for local single-page sites. It uses no images, only gradients.

Unless the user explicitly has light mode as their system preference, the default state of this switch is dark mode.

The switch provides and manipulates the CSS variables `--theme-color-text` and `--theme-color-back`, which can be used as the color source for your website design.

For more information, take a look at `index.html`. It acts both as a nice playground and documentation for the toggle switch.
